# 🚨 Phishing Unfolding

---

## 📖 Overview
This project documents the investigation of a live phishing attack scenario where multiple malicious activities were monitored and analyzed in real time.

The objective was to identify the attack chain, investigate suspicious behavior, and create a detailed incident report based on observed events.

---

## 🎯 Scenario Objectives

- Monitor and analyze real-time security alerts  
- Investigate malicious PowerShell executions  
- Detect reverse shell connections and suspicious DNS activity  
- Document findings and create an incident response case report  

---

## 🛠️ Skills Demonstrated

- Security Monitoring & Alert Analysis  
- Incident Investigation  
- Threat Detection  
- PowerShell Analysis  
- Network & DNS Investigation  
- Documentation & Reporting  

---

## 🔧 Tools Used

- Splunk  

---

## ✅ Outcome
This investigation provided hands-on experience in understanding how a SOC Analyst monitors, analyzes, and responds to real-time cyber attacks.

It demonstrated how security teams can identify suspicious activity early and take action to stop an attack before it causes further damage.
