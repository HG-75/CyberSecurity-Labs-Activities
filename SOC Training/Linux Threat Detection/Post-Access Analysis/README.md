# 🔍 Linux Post-Access Attack Analysis

## 🎯 Objectives

* Detect **Discovery** commands in Auditd logs and trace their origin using **process tree analysis**.
* Identify **Ingress Tool Transfer** activity through process creation and authentication logs.
* Investigate **cryptominer infection chains** from Initial Access through persistence and malware deployment.
* Analyze the **Dota3 malware case**, covering SSH brute-force attacks, Discovery activities, and cryptominer installation.

---

## 🛠️ Tools & Resources

### 📄 auth.log

Used for:

* Detecting successful SSH logins from untrusted IP addresses.
* Tracing SSH brute-force attacks and successful compromises.

### 📊 Auditd

Used for:

* Runtime process creation monitoring.
* Tracing Discovery commands, file transfers, and malware execution back to their origin.

### 📜 Bash History

Used for:

* Recovering attacker-executed commands during interactive SSH sessions.

---

## 🔎 Investigation Steps

### 1️⃣ Discovery Activity Analysis

* Executed Discovery commands on the virtual machine.
* Identified virtualization environment details.
* Checked for running antimalware and security-related processes.

### 2️⃣ Process Tree Investigation

* Investigated an alert generated by the `hostname` command.
* Traced the execution back to a malicious script using process tree analysis.
* Identified the final Discovery command executed by the script.
* Retrieved the script author's email address from the script contents.

### 3️⃣ Ingress Tool Transfer Analysis

* Queried Auditd logs for file download activity.
* Identified the domain used to download the Elastic agent.
* Located the full file path of the downloaded `helper.sh` script.

### 4️⃣ Malicious File Assessment

* Compared downloaded files.
* Determined which file was more likely malicious based on:

  * Download method
  * Execution context
  * Associated activity

### 5️⃣ SSH Compromise Investigation

* Identified the IP address that successfully brute-forced SSH credentials.
* Determined the command used to list recently logged-in users.
* Identified Endpoint Detection & Response (EDR) processes targeted by the attacker.

### 6️⃣ Malware Staging Analysis

* Traced the malicious archive transferred via SCP.
* Identified the hidden staging directory used for malware extraction and deployment.

### 7️⃣ Cryptominer Investigation

* Retrieved the full command line used to launch the Dota3 cryptominer.
* Identified internal network ranges scanned by the bundled network scanning utility.

---

## 🧠 Key Learnings

* Linux attackers typically follow a structured sequence:

  1. 🔍 Discovery
  2. 🛠️ Tool Transfer
  3. ⚡ Persistence & Impact

* Many attacker techniques rely on legitimate administrative tools, making **behavioral context** essential for accurate detection.

* 🌳 **Process tree analysis** remains one of the most effective methods for distinguishing malicious activity from legitimate system administration.

* 📊 Combining **Auditd** and **authentication logs** provides visibility across the entire attack lifecycle, from initial compromise to cryptominer deployment.
