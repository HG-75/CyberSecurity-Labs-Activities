# 🔎 Splunk - Search Processing Language (SPL)

In this room, I explored **Splunk Search Processing Language (SPL)** and learned how to build, filter, structure, and transform search queries to extract meaningful insights from log data.

I also explored how SPL can be used for anomaly detection to identify unusual patterns and potentially suspicious activities.

## 🎯 What I Learned

- 🔍 **Search Operators** – Using search operators to build queries and find relevant events within log data.
- 🧹 **Filtering Results** – Filtering events to narrow down search results and focus on specific information.
- 📊 **Structuring Results** – Organizing and presenting search results in a more meaningful and readable format.
- ⚙️ **Transformative Commands** – Using SPL commands to transform log data and extract useful statistics.
- 🚨 **Anomaly Detection** – Applying SPL techniques to identify unusual patterns and potential anomalies in log data.
