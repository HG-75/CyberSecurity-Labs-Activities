🔐 Splunk VPN Log Analysis (SOC Simulation)
📌 Overview

In this task, I worked with VPN log data in Splunk to simulate how a SOC analyst investigates logs and extracts useful insights.

This is a demo of log analysis and investigation workflow, showing how I query data, filter results, and answer security-related questions.

📸 Refer to the screenshots for step-by-step details of how each query was performed.

🛠️ What I Did
Uploaded the provided VPN log dataset into Splunk
Created a custom index named: VPN_Logs
Explored the data using SPL (Search Processing Language)
Performed multiple queries to extract specific information
🔍 Key Investigations

Using Splunk, I answered the following:

Total number of events in the dataset
Number of events generated by a specific user (Maleena)
Identified the username linked to a specific IP address
Filtered events based on geographic location (excluding France)
Analyzed activity from a specific IP address
🧠 Skills Demonstrated
Log analysis & filtering
Writing SPL queries
Investigating user and IP-based activity
Understanding real-world SOC workflow
Data-driven decision making
⚠️ Note

This project is a simulation/demo to demonstrate how a SOC analyst interacts with a SIEM-like environment using Splunk.
It focuses on investigation techniques rather than a real-world incident.
