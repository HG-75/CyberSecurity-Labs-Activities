# 🔍 EDR Demo – SOC Analyst Workflow

## 📝 Overview

In this exercise, I explored an Endpoint Detection and Response (EDR) platform to understand how SOC analysts investigate endpoint security alerts. The lab focused on reviewing alerts, analyzing endpoint activity, examining attack techniques, and understanding how EDR solutions assist in incident detection and investigation.

---

## 🎯 Objectives

- 🔍 Explore the EDR dashboard and alert interface
- 🚨 Investigate endpoint security alerts
- 🖥️ Analyze process execution and attacker behavior
- 🌐 Review indicators associated with different attack stages
- 🛡️ Understand the role of EDR in SOC investigations

---

## 🛠️ Tools Used

- 🛡️ Endpoint Detection and Response (EDR) Platform
- 🔎 Threat Intelligence

---

## 🔬 Investigation Summary

### 📊 1. Dashboard Exploration

Reviewed the EDR dashboard to understand:

- Alert overview
- Endpoint information
- Investigation workflow

---

### 🚨 2. Alert Investigation

Investigated multiple security alerts to:

- Review alert details
- Analyze attack stages
- Examine endpoint activity

---

### 🖥️ 3. Process Analysis

Reviewed endpoint telemetry to identify:

- Process execution
- Parent-child process relationships
- Suspicious behavioral patterns

---

### 🌐 4. Threat Intelligence Validation

Examined threat intelligence associated with alerts to better understand:

- Indicators of compromise (IOCs)
- Threat context
- Malicious activity

---

## 🚨 Findings

The investigation demonstrated how EDR solutions provide visibility into endpoint activity and assist analysts in investigating security incidents.

Evidence reviewed during the exercise included:

- 🚀 Payload delivery activity
- 🔑 Initial access techniques
- 🔐 Credential dumping activity
- 📤 Data exfiltration attempts
- 🌐 Threat intelligence supporting alert investigations

## 📚 Key Learnings

- EDR platforms provide detailed visibility into endpoint activity.
- Process relationships help analysts understand attacker behavior.
- Threat intelligence adds valuable context during alert investigations.
- Endpoint telemetry enables analysts to reconstruct attack activity.
- Effective alert investigation combines behavioral analysis with supporting evidence.
