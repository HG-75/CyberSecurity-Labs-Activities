# 🌐 Network Analysis with Wireshark

## 📌 Overview
In this room, I explored different network analysis techniques using Wireshark and related tools. The main focus was understanding network traffic, identifying anomalies, analyzing protocols, and investigating suspicious activities.

---

# 🛠️ What I Did

## 1️⃣ Nmap Scanning
- Performed network scans using Nmap
- Identified live hosts and open ports
- Gathered information about services running on devices

---

## 2️⃣ ARP Poisoning & Man in the Middle
- Learned how ARP poisoning works
- Observed Man-in-the-Middle (MITM) attacks in action
- Analyzed manipulated traffic between devices

---

## 3️⃣ Identifying Hosts
- Investigated host-related protocols:
  - DHCP
  - NetBIOS
  - Kerberos
- Learned how devices communicate and identify themselves on a network

---

## 4️⃣ Tunneling Traffic
- Explored covert communication using:
  - ICMP tunneling
  - DNS tunneling
- Analyzed how traffic can bypass normal network monitoring

---

## 5️⃣ Cleartext Protocol Analysis: FTP
- Inspected FTP traffic
- Observed how usernames and passwords are transmitted in plaintext

---

## 6️⃣ Cleartext Protocol Analysis: HTTP
- Analyzed HTTP requests and responses
- Observed visible data transfer without encryption

---

## 7️⃣ Encrypted Protocol Analysis: HTTPS
- Investigated HTTPS traffic
- Learned how encryption protects communication
- Compared encrypted traffic with cleartext protocols

---

## 8️⃣ 🔍 Bonus Hunt — Cleartext Credentials
- Learned how Wireshark can detect cleartext credentials
- Explored the **Tools → Credentials** feature
- Investigated protocols that expose usernames and passwords
- Understood why analysts should not fully rely on automated detections

### 📚 Supported Protocols
- FTP
- HTTP
- IMAP
- POP
- SMTP

---

## 9️⃣ ⚡ Bonus Hunt — Actionable Results
- Learned how to generate security rules directly from Wireshark
- Explored the **Tools → Rules** feature
- Generated rules for blocking suspicious traffic

### 🧩 Supported Rule Formats
- Netfilter (iptables)
- Cisco IOS
- IPFilter
- IPFirewall
- Packet Filter (pf)
- Windows netsh
