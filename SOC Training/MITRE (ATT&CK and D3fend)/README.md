# MITRE ATT&CK & D3FEND – Practical Lab

## Overview

In this lab, I explored how modern security frameworks are used to understand and defend against cyber threats. The focus was on applying MITRE ATT&CK and D3FEND in a practical scenario to simulate real-world SOC analyst workflows.

## What I Learned

* Understood the structure and purpose of the ATT&CK framework
* Mapped attacker behavior using tactics and techniques
* Used threat intelligence concepts to analyze adversary activity
* Explored defensive strategies using the D3FEND framework
* Gained insight into how blue teams detect and respond to threats

## Practical Work

I worked on a hands-on scenario where I:

* Identified attacker techniques using ATT&CK
* Mapped defensive measures using D3FEND
* Analyzed how attacks progress and how they can be mitigated

## Proof of Work

Screenshots are included in this repository as evidence of my work. They demonstrate the steps I followed, analysis performed, and how I applied both frameworks in the scenario.

## Conclusion

This lab helped me bridge the gap between theory and practice by showing how security frameworks are actually used in real-world threat analysis and defense.
