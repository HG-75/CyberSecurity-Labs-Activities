# 🛡️ Threat Simulation & Detection Engineering

---

## 🎯 Objective
After participating in multiple incident response activities, PicoSecure conducted a threat simulation and detection engineering engagement to improve its malware detection capabilities.

In this purple-team exercise, an external penetration tester attempted to execute malware samples on a simulated internal workstation while the defensive team focused on detecting and preventing malicious activity.

The primary objective was to increase the adversary’s operational cost by implementing detections and preventive controls following the Pyramid of Pain methodology.

---

## 🧪 Sample 1 – File Hash Blocking

### 📌 Overview
For Sample 1, the malware was detected and prevented using its file hash.

### 🔍 Detection Method
I identified the malicious file hash and configured a blocking rule to prevent the malware from executing within the environment.

### 🎯 Purpose
- Detect known malicious files  
- Prevent malware execution  
- Stop repeated use of the same malware sample  

### ✅ Result
The malware execution was successfully blocked after implementing the hash-based detection rule, and the required challenge flag was obtained.

---

## 🌐 Sample 2 – Malicious Domain Blocking

### 📌 Overview
For Sample 2, the malware relied on communication with a malicious domain. To mitigate this activity, I implemented domain-based blocking.

### 🔍 Detection Method
I configured a rule to block the identified malicious domain used by the malware sample.

### 🎯 Purpose
- Prevent communication with malicious infrastructure  
- Block command-and-control (C2) traffic  
- Disrupt malware network activity  

### ✅ Result
The malicious domain communication was successfully blocked, preventing the malware from connecting to external infrastructure. The challenge flag was also obtained successfully.

---

## 🧠 Sample 3 – Detection Engineering Activity

### 📌 Overview
For Sample 3, I analyzed malware behavior and created multiple detection rules to identify and block malicious activity across different layers of the environment.

The detections focused on:

- 🌐 DNS activity monitoring  
- 📡 Network-based detection  
- 🗂️ Registry modification detection  
- ⚠️ Malware execution indicators  

This improved visibility into attacker behavior and strengthened the organization’s defensive posture.

---

## 🌐 DNS Detection Rules

I created DNS detection rules to identify suspicious domain resolution activity generated by the malware sample.

### 🎯 Purpose
- Detect malicious or suspicious DNS queries  
- Identify potential command-and-control (C2) communication  
- Monitor domain-based indicators of compromise (IOCs)  

### ✅ Result
The rules successfully detected suspicious DNS activity associated with the malware execution attempt.

---

## 📡 Sigma Rule – Network Activity Detection

I developed a Sigma rule focused on network-based indicators generated by the malware.

### 🎯 Purpose
- Detect suspicious outbound connections  
- Monitor unusual network behavior  
- Identify communication attempts to malicious infrastructure  

### ✅ Result
The Sigma rule successfully triggered during malware execution and provided visibility into malicious network behavior.

---

## 🗂️ Sigma Rule – Registry Modification Detection

I created another Sigma rule to detect malicious registry modifications performed by the malware sample.

### 🎯 Purpose
- Detect persistence mechanisms  
- Monitor unauthorized registry changes  
- Identify malware attempts to maintain access on the system  

### ✅ Result
The rule successfully detected registry-related malicious activity. The challenge flag was also obtained successfully.

## 🚀 Security Impact
The implemented controls improved detection and prevention capabilities across multiple stages of the attack lifecycle.

By using hash blocking, domain blocking, DNS monitoring, network detection, and registry monitoring, the environment became more capable of identifying and stopping malware activity before it could cause impact.

This engagement demonstrated the importance of layered defense strategies and behavior-based detections in modern cybersecurity operations.
